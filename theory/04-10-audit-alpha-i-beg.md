# 4.10 Аудит вывода постоянной тонкой структуры и её бега

*[← Глава 4](04-zaryad-i-leptony.md) · [Оглавление](index.md)*

> Подглава методологическая: продолжает аудит подглавы [4.9](04-9-audit-podgonki.md), но для электромагнитной константы связи. Проверяет вывод подглавы [4.2](04-2-postoyannaya-tonkoy-struktury.md) на подгонку, цикличность и физическую состоятельность, а затем ставит правильную задачу: **вывести не число, а бег**.
>
> **Два результата.** Первый отрицательный и структурный: величина $\alpha_0 = 1/(48\pi)$ лежит **ниже физического минимума** бегущей константы и потому не может быть её значением ни при какой энергии. Второй положительный и конкретный: вклад **одного поколения** в коэффициент бега, $b_{\text{пок}} = 1 + 3\cdot\tfrac49 + 3\cdot\tfrac19 = \tfrac83$, модель выводит **без единого подгоночного параметра**. Полный коэффициент $b = \tfrac83 n_f = 8$ требует числа поколений, которое берётся из эксперимента (раздел 4.10.6 и подглава [4.11](04-11-ontologiya-ekranirovaniya.md)).

## 4.10.1 Правильная постановка задачи

Вывести «постоянную тонкой структуры» как одно число — задача плохо поставленная, поскольку такого числа не существует. Электромагнитная константа связи **бежит**: её значение зависит от переданного импульса.

$$\frac{1}{\alpha(s)} = \frac{1}{\alpha(0)} - \frac{1}{3\pi}\sum_f N_c Q_f^2\left[\ln\frac{s}{m_f^2} - \frac53\right]$$

Модель, претендующая вывести электромагнетизм из структуры вакуума, обязана поэтому воспроизвести **функцию**, а не точку:

1. **величину** в каком-то одном опорном пределе;
2. **наклон** — коэффициент при логарифме;
3. **пороги** — ступени наклона при пересечении масс заряженных частиц;
4. **замораживание** ниже массы электрона.

Пункты 2–4 гораздо содержательнее пункта 1, потому что в них нет свободы вовсе.

## 4.10.2 Три значения, которые нельзя смешивать

| Величина | Значение | Смысл |
|---|---|---|
| $\alpha_0 = 1/(48\pi)$ | $1/150.796$ | «голый топологический заряд» модели |
| $\alpha(0)$ | $1/137.036$ | томсоновский предел, $q^2 \to 0$ |
| $\alpha(m_Z)$ | $1/127.951$ | на полюсе $Z$-бозона |

Подглава [4.2](04-2-postoyannaya-tonkoy-struktury.md) заявляет вывод второго значения из первого. Проверим этот переход по трём независимым основаниям.

## 4.10.3 Проверка на цикличность: цепочка чиста

Первое, что заподозрит критик, — не подставлено ли измеренное значение $\alpha$ внутрь вывода. Проверка по шагам:

| Шаг | Использует измеренную $\alpha$? | Источник |
|---|---|---|
| $\alpha_0 = 1/(48\pi)$ | нет | счёт $3 \times 2 \times 8\pi$ |
| $\cosh\eta_0 = (2\pi/\alpha_0)^{1/4}$ | нет | только $\alpha_0$ |
| Множитель $1 - \alpha_0/2\pi$ | нет | только $\alpha_0$ |
| $\eta_{\text{эфф}}$ | нет | предыдущие |
| $\tau_n$, $\Gamma_n$ | нет | $\eta_{\text{эфф}}$ |

$$\boxed{\ \text{Измеренное значение } \alpha \text{ в цепочку вывода не входит. Цикличности нет.}\ }$$

Это существенный плюс, и его следует отмечать явно: в отличие от спектра масс (подглава [4.9](04-9-audit-podgonki.md)), здесь **нет подгоночных параметров вовсе**. Величина $\alpha_0$ фиксирована счётом, всё остальное из неё следует.

## 4.10.4 Проблема знака: $\alpha_0$ лежит ниже физического минимума

Здесь обнаруживается затруднение более серьёзное, чем известное численное расхождение пункта [T-6](98-todo.md#t-6).

**Направление бега в КЭД.** Поляризация вакуума **экранирует** заряд: чем дальше от заряда (чем меньше переданный импульс), тем слабее наблюдаемая связь. Отсюда $\alpha$ растёт с энергией:

$$\frac{\alpha(m_Z)}{\alpha(0)} = 1.071 > 1$$

**Замораживание внизу.** Ниже массы электрона заряженных частиц не остаётся, поляризовать нечего, и бег прекращается. Следовательно

$$\boxed{\ \alpha(0) = 1/137.036 \ \text{есть АБСОЛЮТНЫЙ МИНИМУМ бегущей константы}\ }$$

Значения меньшего не существует **ни при какой энергии**.

**Между тем**

$$\alpha_0 = \frac{1}{150.796} \ < \ \alpha(0) = \frac{1}{137.036}, \qquad \text{на } 9.13\%$$

Отсюда два следствия, оба неприятных.

**Первое.** Величина $\alpha_0$ не может быть значением бегущей константы связи ни в каком пределе — ни голым зарядом (голый заряд в КЭД **больше** экранированного, а не меньше), ни асимптотическим значением на бесконечном расстоянии (им является само $\alpha(0)$).

**Второе.** Переход от $\alpha_0$ к $\alpha(0)$ требует **усиления**:

$$\frac{\alpha(0)}{\alpha_0} = 1.100415 \qquad (+10.041\%)$$

тогда как множитель $\Gamma_{int} = 0.048287$ из подглавы [4.2](04-2-postoyannaya-tonkoy-struktury.md) даёт **подавление** в $20.7$ раза. Расхождение, таким образом, не только количественное (в $22.8$ раза, как установлено в [T-6](98-todo.md#t-6)), но и **по знаку эффекта**: требуется множитель больше единицы, а предъявлен меньше.

**Что это означает для модели.** Либо $\alpha_0$ есть чисто геометрическая величина, никак не являющаяся константой связи, и тогда соотношение $\alpha = \alpha_0 \cdot \Gamma_{int} \cdot (\ldots)$ есть условие сшивки, требующее отдельного обоснования, — либо в цепочке ошибка. Третьего не дано.

## 4.10.5 Что именно надо воспроизвести, чтобы вывести бег

Наклон бега задаётся безразмерной суммой квадратов зарядов, взвешенных цветовой кратностью:

$$b = \sum_f N_c\, Q_f^2$$

Разложение по семействам при энергии выше всех порогов:

| Семейство | $N_c$ | $n_f$ | $Q^2$ | Вклад |
|---|---|---|---|---|
| заряженные лептоны $e, \mu, \tau$ | 1 | 3 | $1$ | $3$ |
| верхние кварки $u, c, t$ | 3 | 3 | $4/9$ | $4$ |
| нижние кварки $d, s, b$ | 3 | 3 | $1/9$ | $1$ |
| | | | **ИТОГО** | $\mathbf{8}$ |

## 4.10.6 Главный результат: вклад одного поколения выводится без параметров

Вот где у модели есть настоящий, а не мнимый шанс. Из трёх сомножителей в сумме $\sum N_c Q_f^2$ два модель выводит, третий берёт из эксперимента:

| Сомножитель | Значение | Откуда в модели | Подгонка |
|---|---|---|---|
| $Q = 2/3$, $1/3$ | дробные заряды | замыкание цветового контура, $\delta\varphi/4\pi = 1/3$, подглавы [5.2](05-2-drobnyy-zaryad.md) и [5.11](05-11-deficit-obhoda.md) | нет |
| $N_c = 3$ | три цвета | трёхмерность пространства, подглава [5.1](05-1-su3-iz-3d-geometrii.md) | нет |
| $n_f = 3$ | три поколения | **взято из эксперимента** — см. пояснение ниже | **да** |

$$\boxed{\ \sum N_c Q_f^2 = 3\cdot 1 + 3\cdot 3\cdot\tfrac49 + 3\cdot 3\cdot\tfrac19 = 3 + 4 + 1 = 8\ }$$

> **Пояснение к строке $n_f = 3$** (подробнее — подглава [4.11](04-11-ontologiya-ekranirovaniya.md)). Число поколений моделью **не выводится** — оно взято из эксперимента. Соотношение Коиде как правило отбора не работает ([4.6](04-6-koide-i-otbor-urovney.md)), а числовое предсказание массы лептона четвёртого поколения ($9\text{–}45$ ГэВ) опровергнуто границей LEP $m_{L_4} > 100.8$ ГэВ ([4.8](04-8-chetvertoe-pokolenie-status.md)). Действующего вывода числа поколений у модели нет.
>
> Корректная формулировка: **выводится вклад одного поколения**
>
> $$b_{\text{пок}} = 1 + 3\cdot\tfrac49 + 3\cdot\tfrac19 = \tfrac83$$
>
> и вот он действительно свободен от подгонки. Полный коэффициент $b = \tfrac83 n_f$ требует независимого определения $n_f$; сверху оно ограничено условием «полюс Ландау выше планковского обрезания»: $n_f \le 5$ ([4.11](04-11-ontologiya-ekranirovaniya.md), раздел 4.11.5).

**Два сомножителя из трёх свободны от подгонки.** Это всё равно принципиально лучше положения со спектром масс (подглава [4.9](04-9-audit-podgonki.md)), где подгоночных величин оказалось пять на три наблюдаемых.

Более того, набор частиц, входящих в эту сумму, — в точности «сетка частиц поляризации вакуума», введённая моделью самостоятельно в подглаве [4.5](04-5-spektr-na-setke-polyarizacii.md). Внутренняя согласованность здесь есть.

**Практическое следствие.** Задача «вывести бег $\alpha$» сводится к тому, чтобы показать: механизм экранирования в упругой среде даёт логарифм с коэффициентом $1/3\pi$ на единицу $N_c Q^2$. Коэффициент $1/3\pi$ — единственное, что предстоит получить из динамики среды; всё остальное уже выведено.

## 4.10.7 Ступени порогов как отдельный тест

Наклон меняется скачком при каждом пороге. Полная лестница:

| $\mu$, МэВ | Активных | $\sum N_c Q^2$ | Состав |
|---|---|---|---|
| $< 0.511$ | 0 | $0$ | — (бега нет) |
| $2.16$ | 1 | $1.000$ | $e$ |
| $4.67$ | 2 | $2.333$ | $e, u$ |
| $93.4$ | 3 | $2.667$ | $e, u, d$ |
| $105.7$ | 4 | $3.000$ | $e, u, d, s$ |
| $1270$ | 5 | $4.000$ | $+\mu$ |
| $1777$ | 6 | $5.333$ | $+c$ |
| $4180$ | 7 | $6.333$ | $+\tau$ |
| $172690$ | 8 | $6.667$ | $+b$ |
| $> 172690$ | 9 | $\mathbf{8.000}$ | $+t$ |

Это **девять независимых чисел**, каждое из которых модель обязана воспроизвести и ни одно из которых не подгоняется. Куда более жёсткий тест, чем согласие в одной точке.

### Замораживание ниже $m_e$ — дополнительное ограничение на среду

Отдельного внимания заслуживает первая строка. Ниже массы электрона $\sum N_c Q^2 = 0$, и бег **прекращается полностью**: $\alpha$ заморожена на $1/137.036$ вплоть до нулевой энергии, что и подтверждается атомной физикой и измерениями $g-2$.

Для модели это жёсткое требование к среде. Если вакуумная упаковка поляризуется на **всех** масштабах — а ячейки присутствуют везде, — то бег должен был бы продолжаться и ниже $m_e$. Наблюдения это исключают.

**Следовательно: собственная структура среды не должна давать вклада в поляризацию на доступных энергиях.** Экранирование обязано порождаться исключительно реальными заряженными возбуждениями (солитонами), а не самой решёткой.

> **Ограничение снято выводом** в подглаве [4.11](04-11-ontologiya-ekranirovaniya.md): решётка топологически тривиальна и потому не несёт заряда, который можно было бы разделить; поляризация требует рождения пары узел–антиузел ценой $2m_ec^2$. Вакуум оказывается **щелевым диэлектриком**, а замирание бега ниже $m_e$ — обычным поведением диэлектрика на частотах ниже щели. Отдельного постулата не требуется.

| $\Delta\alpha_{\text{адр}}(m_Z)$ | $0.02766 \pm 0.00010$ | из данных $e^+e^- \to$ адроны |
| $\Delta\alpha_{\text{итог}}$ | $0.05908$ | |

Расхождение $0.77\%$ — обычная точность однопетлевого приближения, высшие порядки его закрывают. Существенно, что **лептонная часть вычисляется точно**, без обращения к эксперименту: это и есть та величина, с которой модель должна сравниваться в первую очередь.

## 4.10.9 Протокол и вердикт

### Что установлено

| Пункт | Итог |
|---|---|
| Цикличность вывода | **отсутствует** — измеренная $\alpha$ в цепочку не входит |
| Подгоночные параметры в цепочке $\alpha_0 \to \eta_{\text{эфф}}$ | **ноль** |
| Физическая состоятельность $\alpha_0$ | **нарушена** — лежит ниже абсолютного минимума $\alpha(0)$ |
| Знак требуемого множителя | **противоположен** предъявленному ($1.100$ против $0.048$) |
| Возможность вывести коэффициент бега | **есть, и без параметров**, но лишь на одно поколение: $b_{\text{пок}} = 8/3$; полный $b = \tfrac83 n_f$ требует $n_f$ из эксперимента |

### Что требуется сделать

1. **Определить статус $\alpha_0$.** Либо это константа связи — и тогда значение $1/150.796$ противоречит существованию минимума $1/137.036$; либо это чисто геометрический счётный множитель — и тогда соотношение с физической $\alpha$ нуждается в выводе, а не в постулировании.
2. **Получить коэффициент $1/3\pi$** из динамики упругой среды. Всё остальное в формуле бега модель уже выводит.
3. **Воспроизвести девять ступеней порогов** — тест на порядок жёстче согласия в одной точке.
4. **Показать, что сама решётка не поляризуется** ниже $m_e$, иначе замораживание $\alpha$ не воспроизводится.

### Вердикт

**Вывод постоянной тонкой структуры как числа не состоялся** — из-за проблемы знака он не спасается даже устранением численного расхождения в $22.8$ раза.

**Но задача вывода бега поставлена корректно и наполовину решена.** Вклад одного поколения $b_{\text{пок}} = 8/3$ следует из уже имеющихся утверждений модели без единого подгоночного параметра, а вместе с ним — структура всех девяти ступеней порогов. Недостающих звеньев два: множитель $1/3\pi$ из динамики среды и число поколений $n_f$, которое пока берётся из эксперимента (сверху ограничено: $n_f \le 5$, подглава [4.11](04-11-ontologiya-ekranirovaniya.md)).

Формулировка, допустимая сегодня: *модель выводит структуру бега электромагнитной константы (какие частицы вносят вклад и с каким весом), но не её нормировку.*

Новый пункт дорожной карты — [T-21](98-todo.md#t-21).

## Итоговые соотношения

Бег в однопетлевом приближении:

$$\frac{1}{\alpha(s)} = \frac{1}{\alpha(0)} - \frac{1}{3\pi}\sum_f N_c Q_f^2\left[\ln\frac{s}{m_f^2} - \frac53\right]$$

Абсолютный минимум бегущей константы:

$$\alpha(0) = \frac{1}{137.036}, \qquad \alpha_0^{\text{модели}} = \frac{1}{150.796} < \alpha(0) \ \Rightarrow \ \text{физически недостижимо}$$

Требуемый множитель против предъявленного:

$$\frac{\alpha(0)}{\alpha_0} = 1.1004 \ (\text{усиление}), \qquad \Gamma_{int} = 0.0483 \ (\text{подавление})$$

Коэффициент бега: вклад одного поколения выводится, полный требует $n_f$ из эксперимента:

$$b_{\text{пок}} = 1 + 3\cdot\tfrac49 + 3\cdot\tfrac19 = \tfrac83, \qquad \sum_f N_c Q_f^2 = \tfrac83 n_f = \underbrace{3}_{\text{лептоны}} + \underbrace{4}_{u,c,t} + \underbrace{1}_{d,s,b} = 8 \quad (n_f = 3)$$
