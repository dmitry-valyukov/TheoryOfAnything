# 7.5 Гравитационные волны: чем они являются в среде

*[← Глава 7](07-gravitaciya.md) · [Оглавление](index.md)*

> **Коротко:** проверка гипотезы «продольная ветвь есть гравитационные волны» и ответ на вопрос, о котором модель до сих пор молчала. Гипотеза закрывается по симметрии. Гравитационные волны в модели при этом есть — это волны корреляционного тензора дрожания, и все наблюдаемые их признаки получаются без подгонки.

Расчёты — `simulations/python/GravitationalWaves.py`.

## 7.5.1 Что известно из опыта

| признак | значение |
|---|---|
| скорость | $\|c_{gw}/c - 1\| \le 10^{-15}$ (GW170817 + GRB 170817A) |
| характер | поперечные, бесследовые |
| тензорный ранг | $2$, симметричный |
| число поляризаций | $2$ ($h_+$ и $h_\times$) |
| низший излучающий мультиполь | квадруполь |
| монопольное и дипольное излучение | запрещено |
| характерная амплитуда у Земли | $h \sim 10^{-21}$ |

## 7.5.2 Гипотеза «продольная ветвь = ГВ» закрыта

Проверка идёт по трём независимым признакам, и все три дают отрицательный ответ.

| признак | продольная ветвь | наблюдение | итог |
|---|---|---|---|
| тензорный ранг | скаляр, спин $0$ | тензор, спин $2$ | **против** |
| скорость | $\gg c$, а при строгой несжимаемости не мода вовсе | $= c$ до $10^{-15}$ | **против** |
| число поляризаций | $1$ | $2$ | **против** |

Первый признак решающий и он **по симметрии**, а не по величине. Продольная волна есть смещение вдоль волнового вектора, $\mathbf u \parallel \mathbf k$, и описывается одной скалярной функцией. Гравитационная волна есть симметричный бесследовый поперечный тензор. Никакой выбор параметров среды скаляр в тензор не превращает.

Гипотеза, следовательно, закрыта окончательно, а не «пока не подтверждена».

## 7.5.3 Чем гравитационные волны являются в модели

Ответ следует из того, чем является сама гравитация. Она есть модуляция модуля сдвига ([7.1](07-1-sbros-stressa.md), [8.1](08-1-plavlenie-vakuuma.md)):

$$\frac{\mu}{\mu_\infty} = \left(1 - \frac{\delta\langle u^2\rangle}{\langle u^2\rangle_L}\right)^2$$

Значит гравитационная волна есть распространяющаяся модуляция $\mu$, то есть **волна избыточного дрожания**. А дрожание описывается не вектором смещения, а его **корреляционным тензором**:

$$h_{ij} \ \sim \ \delta\langle u_i u_j\rangle$$

**Гравитационная волна есть волна корреляционного тензора, а не волна поля смещений.** Это объект второго порядка по амплитуде — ровно того же порядка, в каком живёт вся гравитация модели ([1.6.4](01-6-mgnovennoe-pole-davleniya.md)).

Отсюда все наблюдаемые признаки получаются сразу, и ни один не подгоняется:

| признак | как получается |
|---|---|
| симметричный тензор ранга $2$ | $\langle u_iu_j\rangle$ симметричен по построению |
| бесследовость | след есть $\langle u^2\rangle$, и связь $\nabla\cdot\mathbf u = 0$ его вычищает |
| поперечность | носитель — сдвиговая ветвь |
| скорость $= c$ | несёт та же ветвь, что и свет |
| две поляризации | счёт компонент, раздел 7.5.4 |
| квадрупольность | двойная дивергенция источника ([1.6.4](01-6-mgnovennoe-pole-davleniya.md)) |
| нет монополя и диполя | сохранение импульса, там же |
| второй порядок по амплитуде | $h \sim \langle uu\rangle$, а не $\sim u$ |

Признак «скорость $= c$» здесь не совпадение: гравитация идёт по **сдвиговой** ветви, той же, по которой идёт свет ([1.6.7](01-6-mgnovennoe-pole-davleniya.md)), поэтому проверку GW170817 модель проходит тождественно. Гипотеза про продольную ветвь проваливала бы её на пятнадцати порядках.

## 7.5.4 Счёт поляризаций: почему ровно две

$$\underbrace{6}_{\text{симметричный } h_{ij} \text{ в } D=3} \ - \ \underbrace{3}_{k_ih_{ij}=0} \ - \ \underbrace{1}_{\text{след}} \ = \ \mathbf{2}$$

Для волны вдоль $z$ остаются $h_{xx} = -h_{yy}$ и $h_{xy}$ — это и есть $h_+$ и $h_\times$.

**Ключевой шаг — последний, и он даёт модели содержательное отличие от общей теории относительности.** Бесследовость гравитационной волны в ОТО вводится **калибровкой** (TT-калибровка) — это удобный выбор, а не физическое условие. Здесь она не выбирается: след тензора $\langle u_iu_j\rangle$ есть $\langle u^2\rangle$, а связь несжимаемости $\nabla\cdot\mathbf u = 0$ объёмную деформацию запрещает.

Условие TT оказывается **материальной связью**, а не калибровкой. Это проверяемо: при отказе от строгой несжимаемости появилась бы третья, скалярная поляризация — ровно то, что ограничивает сеть детекторов.

**Несжимаемость тем самым получает пятый независимый мотив** ([1.6.1](01-6-mgnovennoe-pole-davleniya.md)): помимо гравитации, конфайнмента, электродинамики и неравенств Белла — ещё и число поляризаций гравитационных волн.

## 7.5.5 Числовая сверка

| величина | значение |
|---|---|
| амплитуда события LIGO | $h \sim 10^{-21}$ |
| смещение плеча ($L = 4$ км) | $\delta L = 4\cdot10^{-18}$ м |
| гравитационный радиус Солнца | $r_s = 2954$ м |
| $\delta\langle u^2\rangle/\langle u^2\rangle_L$ у Земли от Солнца | $2.0\cdot10^{-8}$ |
| добавка от проходящей волны | $10^{-21}$ |

Порядки согласуются с картиной: постоянное поле Солнца сдвигает среду на $2\cdot10^{-8}$ пути к расклиниванию, проходящая волна добавляет ещё $10^{-21}$. Среда у Земли глубоко в заклиненной фазе, и линеаризация $(1-x)^2 \approx 1 - 2x$ здесь заведомо законна.

## 7.5.6 Что измеряет интерферометр

В общей теории относительности интерферометр измеряет деформацию пространства-времени. В модели пространство не деформируется — оно вообще не является объектом. Измеряется другое:

$$\text{волна дрожания} \ \to \ \text{модуляция } \mu \ \to \ \text{модуляция } c = \sqrt{\mu/\rho} \ \to \ \text{время пробега луча} \ \to \ \text{сдвиг полосы}$$

**LIGO измеряет не растяжение пространства, а модуляцию скорости света бегущей волной избыточного дрожания среды.** Наблюдаемая величина та же, онтология другая.

Отсюда — самостоятельный фальсифицируемый след, которого у модели не было. В ОТО деформация действует на линейку и на луч **одинаково**, и потому эффект выражается одним безразмерным $h$. В среде же модуляция $\mu$ действует на скорость волны напрямую, а на размеры вещества — через перестройку равновесия связанных состояний. Совпадают ли два действия **точно**, модель обязана проверить: расхождение проявилось бы как зависимость отклика детектора от материала плеч.

Величина не посчитана — вынесено в [T-41](98-todo.md#t-41).
